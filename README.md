# Guereca Entertainment Mini Arcade System (G.E.M.A.S)

Consola portátil de videojuegos basada en el ESP32-S3 con PCB y carcasa propias.

**[Abrir la wiki de G.E.M.A.S.](wiki/Home.md)**

| Carpeta | Contenido |
|---|---|
| [wiki](wiki/Home.md) | Documentación técnica de G.E.M.A.S. |
| [hardware/altium](hardware/altium) | Proyecto de Altium Designer, esquemáticos, revisiones de PCB, BOM editable y configuración de salida. |
| [hardware/componentes](hardware/componentes) | Bibliotecas, modelos y hojas de datos de componentes. |
| [hardware/fabricacion](hardware/fabricacion) | Paquete Gerber y sus archivos descomprimidos. Los nombres de las capas identifican la revisión V2. |
| [hardware/verificacion](hardware/verificacion) | Reportes de reglas de diseño de la etapa final y de V2. |
| [firmware/prueba](firmware/prueba) | Sketch Arduino de demostración v4.2 para ESP32-S3, con pantalla SPI, botones y audio I²S. |
| [mecanica](mecanica) | Piezas y ensamblajes de SolidWorks, modelos STEP y STL. |
| [recursos](recursos) | Esquemático exportado, diagrama de nivel superior, presentación y archivos del logotipo. |

La carpeta de Altium conserva las revisiones de placa identificables. El paquete Gerber debe cotejarse con la revisión que se quiera reproducir.
